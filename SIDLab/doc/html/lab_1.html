Vorbereitung

a) 3 Stimmen b) 28 Pins c) 29 Registers d) 5 Bits e) 8 Bits f) Triangle, Sawtooth, & Pulse g) LP (Tiefpass), BP (Bandpass), & HP (Hochpass) h) Register $18, Bit 0-3 i) Attack: Wie schnell die Ausgangsamplitude einer Voice nach dem Setzen des Gate-Bits von 0 auf die maximale Amplitude ansteigt Decay: Wie schnell die Amplitude danach von der maximalen Amplitude auf das gewählte Sustain-Niveau abfällt Sustain: Das Amplitudenniveau, auf dem die Ausgangsamplitude bleibt, solange das Gate-Bit gesetzt ist Release: Wie schnell die Amplitude nach dem Löschen des Gate-Bits vom aktuellen Niveau auf 0 abfällt j) Gate-Bit, Register 04 Bit 0 k) Es beginnt erneut eine Attack-Phase, und zwar von der aktuellen Amplitude aus, nicht von 0 l) RES = 1; A = 10111; D = 10010110; CS = 0; warte bis Φ2 abfällt; CS = 0
