Detailed Description

SID voice.

Implements the behavior of a single SID voice. The voice drives its four different waveforms (pulses, triangle, sawtooth, noise) and produces an audio mix of these, according to which are enabled. Applies an ADSR envelope (attack, decay, sustain, release) to the mix volume (see datasheet). SID must call onSample() and fetch the output() once each sample (for this implementation, that equals once each clock cycle)

◆ onSample()

void sid_types::Voice::onSample ( u64  a_sampleCtr)

Lets this voice proceed for the duration of one sample.

SID must call this once each sample (in this implementation, that is equal to each cycle). Makes its waveforms proceed for the duration of one sample, calculates the current ADSR envelope volume and produces the current audio mix (which should afterwards be fetched using output())
