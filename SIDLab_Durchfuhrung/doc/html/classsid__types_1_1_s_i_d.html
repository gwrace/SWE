Detailed Description

SID chip simulation.

Simulates the behavior of the Commodore C64's sound chip, the MOS 6581 Sound Interface Device (SID), released in 1982.

This simulation is INCOMPLETE and NOT cycle-accurate. Not implemented:

  • Accurate timing with a PHI2 clock of 1.0MHz - instead, the clock frequency PHI2 equals the sampling rate of 44.1kHz. Cycle-accurracy has been dropped in favour of simulation speed
  • External input
  • Read-only registers (Pin RW is always held low)
  • Filter resonant frequency adjustment (see RES/FILT register)
  • Ring modulation, synchronization, TEST bit
  • ...

Usage:

  • Instantiate a SID.
  • Periodically call onCLK() - once every clock cycle. Store the return value in some container for later playback.
  • Use writePin() to write values to the SID's pins.

◆ onCLK()

float sid_types::SID::onCLK ( )

Generates a negative edge on the PHI2 pin (clock signal), making the SID proceed its work for one cycle. Then returns the resulting audio output value on pin AUDIO_OUT.

This will make the SID proceed with its work for one clock cycle. Call this periodically to achieve a time based simulation. Note that PHI2 = 44.1kHz in this implementation for speed.

Returns
The resulting audio output value on pin AUDIO_OUT, ranging from -1.0 to +1.0.
