#####   waview_2 - SIDLab wav audio viewer & player   -   README.txt   #####

Last updated: 09/26/25

This is a GUI tool that functions as a viewer and player for wave audio files
(WAV).
Currently, only 44100 Hz, 32-bit float, single-channel (mono) WAV files
(the SIDLab output format) are supported.
This is a Windows application, but can be run under Linux using wine.
